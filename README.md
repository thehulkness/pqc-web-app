# PQC Web App A web application demonstrating symmetric encryption using Flask and the `cryptography.fernet` library, originally intended to integrate Post-Quantum Cryptography (PQC) algorithms. ## Overview This project showcases a simple web-based cryptography tool with key generation, encryption, and decryption functionality. The initial goal was to implement a PQC algorithm (e.g., Kyber or Dilithium from `liboqs-python`) to resist quantum computer attacks, but due to compatibility issues on Windows, it uses Fernet (AES-128 with HMAC-SHA256) as a fallback. The app features a futuristic, tech-inspired design and includes a Jupyter notebook documenting the development process. ## Features - Generate a symmetric encryption key. - Encrypt plaintext messages. - Decrypt ciphertext messages. - Futuristic UI with gradient background and neon accents (main page only; result pages have a rendering issue). - Error handling for invalid inputs or missing keys. ## Installation 1. Clone the repository: ``` git clone https://github.com/thehulkness/pqc-web-app.git cd pqc-web-app ``` 2. Install dependencies: ``` pip install -r requirements.txt ``` 3. Set up environment variables (optional, based on `.env.example`). 4. Run the app: ``` python app.py ``` 5. Access the app at `http://localhost:5000`. ## Usage - Visit the main page to generate a key, encrypt a message, or decrypt a ciphertext. - Note: Due to a rendering issue, encryption and decryption results display as plain text on a white background instead of the intended themed template. ## Project Structure ``` pqc-web-app/ ├── docs/              # Screenshots and documentation images │   ├── main_page.png │   ├── encryption_result.png │   ├── decryption_result.png │   ├── error_result.png ├── static/            # Static files │   ├── styles.css     # Custom CSS for the futuristic theme ├── templates/         # HTML templates │   ├── index.html     # Main application page │   ├── result.html    # Intended result page template (not rendering correctly) ├── app.py             # Flask application logic ├── notebook.ipynb     # Development notebook with report ├── README.md          # This file ├── requirements.txt   # Python dependencies ├── .env.example       # Example environment variable file ``` ## Dependencies - Flask - cryptography - flask-talisman ## Limitations - **No PQC Integration**: Intended to use `liboqs-python` for Kyber or Dilithium, but compatibility issues prevented this. - **Rendering Issue**: The `result.html` template fails to render, showing plain text results due to a Jinja2 configuration problem. ## Future Improvements - Resolve compatibility issues to integrate `liboqs-python` for PQC. - Fix the Jinja2 rendering issue to display themed result pages. - Add client-side validation or animations with JavaScript. ## License [MIT License](LICENSE) (or specify your preferred license; create a `LICENSE` file if needed).
